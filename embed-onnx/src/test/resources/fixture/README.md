# Offline ONNX adapter fixture

`model.onnx` and `tokenizer.json` are generated by
`embed-onnx/tools/generate_test_fixture.py`. The graph performs a fixed token-id lookup into four
dimensions; it is not a learned encoder and is never benchmark evidence.

The fixture exists so unattended tests exercise DJL tokenization, ONNX tensor binding, batched
padding, attention-mask mean pooling, and L2 validation without downloading model weights.
