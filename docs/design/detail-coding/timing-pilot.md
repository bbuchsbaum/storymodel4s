For family f, preserve active minutes m_f and completed rows n_f. If n_f > 0,
r_f = m_f / n_f minutes/row; if n_f = 0, rate is unavailable, not zero. For workload N_f:
T_active = sum(N_f × r_f) only for observed rates. Report T_review, T_adjudication and
T_contingency separately; T_total is their sum with T_active. Calendar elapsed time is not active
coding time.

T_active = 5×4 + 4×5 = 40 minutes before separately declared components. No staffing or
