`SurfaceRendering.pair` retrieves a unit from a checked recall graph and a target from a captured
source view. It requires the declared source checksum to match actual canonical text, the
representation's view fingerprint and semantic scope to match the snapshot, and physical target
support to equal the node's support. It validates original span bounds, optional anchors, Unicode
and surrogate boundaries, and checks the entire parent inventory for cycles before recursive
projection. This establishes a declaration-to-text join, not acquisition or annotation authority.

The unforgeable `RenderedContentPair` contains canonical content, admitted grain, exact rendered
strings and the rendering-policy identity. It retains no source objects, references, coordinates,
callback or binding envelope. Equality distinguishes changed strings; its public hash does not
derive from those strings. Existing content-only equivalence, fixture tables and historical
scoring are unchanged. Recall preserves its checked hull text; target rendering merges supported
runs and separates gaps by one newline. Empty spans are validated then removed, preventing
separator-only invented material. This does not undo a hull introduced by an upstream producer.
Anchored media/caption inputs remain refused by this text-only boundary.

`EmbeddingMetric.fromCosine` explicitly consumes raw finite `[0,2]` distance and returns a checked
value retaining either raw units or half-cosine units (`d / 2`, `[0,1]`). It preserves observation
credence, eligible missing and ineligible outcomes. Conversion refuses invalid values instead of
clamping; it does not change the existing vector routine's numerical clamp or grant execution
or registration authority. Half-cosine preserves ranking, not weighted historical cost parity.
