# M1 plan — unattended vertical slice, embeddings, and TODO closure (revision 2)

**Status:** Draft, revision 2 (co-authored on mote; applies Codex's plan-order
correction; beads open after ADR 0001 rev 3 is accepted).
**Goal reminder:** the best library in existence for representing stories,
human recall, and the mapping between them — including the Autobiographical
Interview. M1 turns the M0 foundation into the first *unattended, auditable*
build with evidence-selected embeddings, without letting similarity adjudicate
and without converting distortion into omission plus intrusion.

## Exit criteria (roadmap rev 2, unchanged)

Several pages ingest unattended; exact cache replay; WOG §27.2 prohibitions
hold under conservative automatic policy; G0–G1 pass; the M0 `TODO(M5)`/
`TODO(M3)` items are closed by calibrated (adjudicated) defaults, not by
loosened assertions.

## Workstreams, in the order they must land

### W1 Anchor/fidelity modes and the non-bypassable gate — claude → codex
1. `align`: state space becomes (anchor, `FidelityMode`); contradictions make
   `(c, Faithful)` inadmissible and leave `(c, Distorted(facets))`; context is a
   facet; `GraphHsmm` owns a typed mode-gate prepass; production `gating=false`
   removed; ungated behaviour only behind `AblationResult`. Candidate
   nominations preserved with channel/rank/raw score/space/receipt.
   `RecallSignature` reports anchored-distorted mass separately from omission
   and intrusion. WOG foil assertions become "anchored as Distorted, never
   Faithful". Laws L1–L3 in `laws.AlignmentLaws` with adversarial generators.
2. `embed-core`: `ProviderFingerprint` / `EmbeddingSpace` / `GeometryPair`,
   `RequestId`, `EmbedBatch` → `BatchResult` with `AttemptReceipt`,
   `ValidatedVector`/`ValidatedDistance`, views, free baselines with
   fingerprinted corpora/seeds, `EmbeddingCache` interface, `SensitiveDigest`
   type; laws L4, L6 shapes; JVM/JS/Native.

### W2 Proposition evidence and structural coverage — claude → codex
3. `PropositionEvidence` channel on `RecallUnit` and `NodeSummary`/
   `AlignmentSource` (`Option[PropositionChart[Checked]]` with provenance);
   `d_chart` (ChartCompatibility), `d_sketch` (labelled fallback), `d_sem`,
   `d_wl` defined separately with a declared lawful composition; leaf vs segment
   structural coverage (documented member-chart reducer).
4. `embed-grakern` (JVM-only): reification with explicit source/target
   incidence; reversal non-isomorphism test; G1–G2 through reification; SHA
   pins with receipt recording; clean-clone proof.
5. grakern upstream beads (grakern/.mote): protocol → directed WL, portable
   emitter, overlay hardening, edge policy; laws; 0.1.0-M1.

### W3 Authorized requests, receipts, providers — codex → claude
6. `PseudonymizedText` / `ReidentificationKey` split in `interview`;
   `RemotePolicy.evaluate` → `AuthorizedRemoteRequest` + `RemoteCapability`
   (provider, model, purpose, policy, expiry, budget, payload digest);
   `EmbeddingReceipt` with `SensitiveDigest`; sanitized errors/logs.
7. `embed-onnx` (DJL tokenizer, differential goldens; bge/e5/nomic/gte; token
   embeddings for late pooling with full identity).
8. `embed-transport` + codecs; keyed cache + `EncryptedStore`.

### W4 Frozen fixtures and benchmark — claude builds, codex audits independence
9. Fixture-freezing tooling and adjudication protocol; frozen selection set
   (≥ 8 stories, ≥ 3 families; charts, hierarchy, summaries, acceptable target
   sets, alternatives, external labels) built independently of every tested
   channel; natural human-recall panel; partitions.
10. `embed-bench` per the spike spec rev 2 (strict recall at level, level
    confusion, summary accuracy, blend coverage, candidate burden, MRR, macro
    CIs, gate correctness, separated open-world reports, three-clock panels;
    oracle charts and unattended text).
11. Calibration on adjudicated targets (retrieval and rejection separately);
    decision record in ADR 0001; **closes `TODO(M5)` ×4** (calibrated) or
    leaves them labelled provisional (benchmark-tuned).

### W5 Recall-side participant separation — claude
12. `RecallSegmenter`/`Lexical`: nominal mentions kept distinct ("the young
    man" ≠ "the five men"), number agreement, minimal recall-side coreference;
    **closes `TODO(M3)`**.

### W6 Unattended vertical slice — shared, after W1–W3 contracts
13. `build` orchestrator (JVM); `provider-parser` and `provider-agent` with
    prompt packages v1 and foils; `document` composition and projection under
    conservative policy; `codec` round-trip; CLI.

## Sequencing

```
W1(1) ─▶ W1(2) ─▶ W2(3) ─▶ W2(4) ─┐
                    W3(6) ─▶ W3(7,8) ┼─▶ W4(9) ─▶ W4(10) ─▶ W4(11) ─▶ TODO(M5)
W5(12) ──────────────────────────────────────────────────────▶ TODO(M3)
W1–W3 contracts ─▶ W6(13) ─▶ M1 exit
```

Defaults and calibration are selected only after W4(9) exists; WOG never
selects.

## Non-negotiables carried

ADR 0001 rev 3 laws L1–L6; grakern laws G1–G4 before `embed-grakern` ships;
defaults only from frozen adjudicated fixtures; "calibrated" only against
adjudicated targets; no portable module gains a sibling or JVM-only dependency;
every provider call receipted; sensitive inputs local-only by default; raw and
authorized-remote requests are different types.
