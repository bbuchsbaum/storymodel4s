# M1 plan — unattended vertical slice, embeddings, and TODO closure

**Status:** Draft (co-authored on mote; beads open after Codex's ADR 0001 review).
**Goal reminder:** the best library in existence for representing stories,
human recall, and the mapping between them — including the Autobiographical
Interview. M1 turns the M0 foundation into the first *unattended, auditable*
build with evidence-selected embeddings, without letting similarity adjudicate.

## Exit criteria (from roadmap rev 2, unchanged)

Several pages ingest unattended; exact cache replay; WOG §27.2 prohibitions
hold under conservative automatic policy; G0–G1 pass; **and** the M0
`TODO(M5)`/`TODO(M3)` items in the WOG alignment suite are closed by
calibrated defaults, not by loosened assertions.

## Workstreams and beads (owner → reviewer)

### W1 Embedding contract and portable baselines — claude → codex
1. `embed-core`: contracts, `ValidatedVector`, identity/fingerprints, views,
   `EmbeddingCache` interface + in-memory, `PrivacyPolicy` types, laws L2–L4,
   L6 shapes; hashed n-gram and TF-IDF baselines. Exit: laws green on
   JVM/JS/Native; `align.CandidateGenerator` consumes `Embedder` via
   `SemanticDistance`.
2. `align` integration: candidate provenance per channel on `Candidates`;
   lexicographic objective (gates → facets → graded cost) made explicit; law
   L1 added to `laws.AlignmentLaws` with adversarial generators (arbitrary
   distances/weights/temperatures cannot admit a gated candidate).

### W2 Structural channel via grakern — claude → codex
3. `embed-grakern` (JVM-only): chart → `GraphSample` by relation reification;
   WL subtree/OA; `structural.wl.grakern` provider; SHA pins with build-receipt
   recording; packages.toml `[[dependency]]` blocks; clean-clone build proof.
   Exit: G1/G2 hold through reification; role-swap/polarity foils separate in
   `d_prop`; ablation shows the union effect (spike criterion).
4. grakern upstream beads (filed in grakern/.mote): directed graphs, portable
   emitter, sparse rows + query overlay hardening, self-loop/parallel policy,
   Discipline laws, 0.1.0-M1.

### W3 Local and remote providers — codex → claude
5. `embed-onnx`: ONNX Runtime + DJL tokenizer; differential tokenizer goldens;
   bge-small/base, e5-base, nomic-v1.5 (Matryoshka), gte-base; optional token
   embeddings for the late-pooled view with full receipt (ADR D4d).
6. `embed-transport`: abstract transport + per-provider codecs (OpenAI,
   Voyage, Cohere, Gemini, Jina; Ollama/llama.cpp/TEI/vLLM); budgets, retries,
   receipts.
7. Keyed cache (`HMAC-SHA256`, store-local key) + `EncryptedStore` (JVM);
   `RemoteCapability` bound to a `Pseudonymized` id and `PrivacyPolicyId`;
   receipt audit.

### W4 Benchmark and defaults — claude builds, codex reviews
8. `embed-bench` + metamorphic corpus tooling (multi-story, independently
   generated, audited sample; leave-story-out); metrics per spike spec;
   report generator.
9. Calibration: retrieval and open-world rejection models fitted
   leave-story-out; calibrated `CostWeights`/`externalFloor` defaults;
   decision record appended to ADR 0001; **closes `TODO(M5)` ×4**.

### W5 Recall-side participant separation — claude
10. `RecallSegmenter`/`Lexical`: multiword and determiner-bearing nominal
    mentions kept distinct ("the young man" ≠ "the five men"), number
    agreement, minimal recall-side coreference; **closes `TODO(M3)`**.

### W6 Unattended vertical slice — shared (sequenced after W1–W3 contracts)
11. `build` orchestrator (JVM): stage DAG from `acquire.StageSpec`, cache,
    budgets, receipts, gates.
12. `provider-parser` (one AMR parser service) and `provider-agent` (one
    proposal/critic agent with prompt packages v1 and foils).
13. `document` composition from provider charts; projection into `story`;
    conservative automatic policy for the WOG prohibitions.
14. `codec` (circe) round-trip for all artifacts; CLI `build/validate/inspect/diff`.

## Non-negotiables carried

ADR 0001 laws L1–L6; grakern laws G1–G4 before `embed-grakern` ships;
defaults only from `embed-bench` evidence; no portable module gains a sibling
or JVM-only dependency; every provider call receipted; sensitive inputs
local-only by default.
