# Workbench scaffold

React, TypeScript and Vite are configured. This is a framework smoke build, not an artifact
inspector. The owner prioritized algorithms and representations on 2026-11-16; inspection,
generated TypeScript contracts and visual refinement follow the computational path.

```sh
cd port/web
npm ci
npm run build
npm run dev
```

The eventual workbench reads the Python-owned account and analysis schema in
`../schemas/exchange.json`. It must not implement its own scientific estimators. Build
success does not establish browser behavior or StoryAtlas parity.
