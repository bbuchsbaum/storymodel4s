Every story model begins with a `StorySource`. `SurfaceAnalyzer.analyze` turns that source into a
`SurfaceAtlas`: an index of paragraphs, sentences, and tokens over the canonical text.

For the complete story-to-recall workflow, begin with [Getting started](/scala/getting-started/).

## Prerequisites

- JDK 17 or 21
- sbt 1.12.14
- Scala 3.7.4, supplied by the build
- a local `grakern` checkout for aggregate gates while that dependency remains unpublished

Clone the repository and run its JVM tests:

```sh
git clone https://github.com/bbuchsbaum/storymodel4s.git
cd storymodel4s

sbt -Dstorymodel4s.grakern.build=/absolute/path/to/grakern testJVM
```

```scala
atlas.tokens.map(atlas.text)

```

The analyzer keeps the punctuation token because its span is part of the source text.

## Read exact offsets

Each unit carries a zero-based, half-open UTF-16 span. The sentence occupies `[0, 36)`. Its tokens
occupy these spans:

| Token | Span |
| --- | --- |
| `One` | `[0, 3)` |
| `night` | `[4, 9)` |
| `two` | `[10, 13)` |
| `young` | `[14, 19)` |
| `men` | `[20, 23)` |
| `left` | `[24, 28)` |
| `Egulac` | `[29, 35)` |
| `.` | `[35, 36)` |

The atlas can find the unit at one offset or every unit that overlaps a span:

```scala
atlas.unitAt(25, SurfaceUnitKind.Token).map(atlas.text)
// Some("left")

atlas
  .unitsOverlapping(TextSpan.unsafe(20, 28), SurfaceUnitKind.Token)
  .map(atlas.text)
// Vector("men", "left")
```

## Turn a span into evidence

Claims elsewhere in the library cite a `SpanSet`. An evidence set may contain one span or several
distant spans.

```scala
val sentence = atlas.sentences.head
val evidence = SpanSet.one(SpanRef(Some(sentence.id), sentence.span))

evidence.coveredLength // 36
evidence.units         // Set(sentence.id)
atlas.text(sentence)   // "One night two young men left Egulac."
```

The atlas answers where the words occur. A story model adds entities, events, states, contexts,
relations, and claims that cite these spans.

## Continue to the story model

The atlas tells you where the words are. A `StoryModel` connects those words to the people, events,
states, contexts, and relations described by the story. This code loads the reviewed *War of the
Ghosts* fixture, whose modeling work is already complete:

```scala
import storymodel4s.fixtures.wog.WarOfTheGhostsModel

val model = WarOfTheGhostsModel.model

model.atlas.sentences.size          // 50
model.graph.entities.size           // 14
model.graph.situations.size         // 71
model.graph.contexts.size           // 12
model.graph.relations.temporal.size // 52
model.graph.relations.causal.size   // 9
model.claims.size                    // 462
```

The story-model guide follows one sentence into two separate records: a young man says something in
the narrated world, and the content of his speech belongs to a nested speech context. It prints each
record's predicate, polarity, context, and supporting sentence.
