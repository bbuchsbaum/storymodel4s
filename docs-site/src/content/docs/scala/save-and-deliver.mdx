export const programPath = 'docs-site/examples/SaveModel.scala';

export const PROGRAM_SHA = '7526d4599c05e7afcdff74e784232e1bbc0cede04b478c646ca4b24483aa1bfa';
export const OUTPUT_SHA = 'cc1f48b09b46f92eaf4b617837b4f343b84ad721cea0e2122048a54ac8217864';
export const PRODUCER_REVISION = '1cb64bd39f097c32233a52ff6e167f9f93d9d127';
export const program = readFileSync(resolve(process.cwd(), 'examples/SaveModel.scala'), 'utf8');
export const output = readFileSync(resolve(process.cwd(), 'examples/save-model.output.txt'), 'utf8');
export const programSha = createHash('sha256').update(program).digest('hex');
export const outputSha = createHash('sha256').update(output).digest('hex');

export const _bindFiles = (() => {
  if (programSha !== PROGRAM_SHA)
    throw new Error(`program digest ${programSha} does not match the published ${PROGRAM_SHA}`);
  if (outputSha !== OUTPUT_SHA)
    throw new Error(`output digest ${outputSha} does not match the published ${OUTPUT_SHA}`);
  return true;
})();

`StoryModelCodec` writes a complete story model as canonical JSON. The same model always produces the
same bytes and content checksum under one schema version. Decoding produces a draft, which the
consumer validates before using APIs that require a validated model.

## What the codec preserves

The JSON contains the source, atlas, narrative graph, hierarchy, discourse trajectory, feature-space
metadata, sidecar manifests, feature references, descriptors, hypotheses, sensory profiles, and
optional build receipt. Vector payloads remain in sidecars.

Validation status is a local type witness. It is omitted from the JSON. A receiver therefore decodes
to `StoryModel[Draft]` and runs `StoryValidator` in its own environment.

## Current delivery boundary

The `view` module can compile a validated model into renderer-neutral `CodexFlow` and
`NarrativeScene` values. HTML, SVG layout, and the interactive application belong to the separate,
unpublished `storyatlas4s` project. This repository currently exposes no `CodexHtml` renderer and no
filesystem-openable HTML bundle command.

The canonical JSON above is therefore the complete portable delivery artifact available from
storymodel4s today. A future bundle guide should show separate outcomes for model compilation,
rendering, and file assembly after that public workflow exists.
