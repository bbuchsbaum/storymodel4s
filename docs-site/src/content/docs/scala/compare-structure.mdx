Word overlap misses relations. “Anna found her brother” and “Her brother found Anna” contain the
same words, but their agent and patient roles are reversed. The structural channel compares checked
proposition graphs and makes that difference visible.

| Pair | Distance | Reading |
| --- | ---: | --- |
| Same graph | 0.000000 | same labels and relations |
| Renamed node IDs, reversed storage order | 0.000000 | identity ignores incidental IDs and order |
| Agent and patient swapped | 0.600000 | role direction changed |
| Different predicate and patient | 0.733333 | more of the labelled structure changed |
| Source outside the prepared dictionary | Missing | no comparison was made |

The adapter runs on the JVM because it uses the pinned grakern source dependency. It memoizes query
rows and records a provider call with the kernel rounds and exact grakern revision. The distance is a
feature for candidate generation or a declared cost. Claim acceptance remains the resolver's job.
