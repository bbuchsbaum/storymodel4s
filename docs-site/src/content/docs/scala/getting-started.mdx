## Prerequisites

- JDK 17 or 21
- sbt 1.12.14 (the repository wrapper metadata pins the build)
- Scala 3.7.4 through sbt
- A local `grakern` checkout when running aggregate gates, until that source dependency is
  published

## Verify the source tree

```sh
git clone https://github.com/bbuchsbaum/storymodel4s.git
cd storymodel4s

sbt -Dstorymodel4s.grakern.build=/absolute/path/to/grakern testJVM
```

The broader repository gate compiles and tests portable modules on JVM, Scala.js, and Scala Native:

```sh
sbt -Dstorymodel4s.grakern.build=/absolute/path/to/grakern checkAll
```

A passing command is evidence about the exact checkout and environment in which it ran. It is not
evidence that an artifact has been released.

## The smallest surface example

This example creates a source document and derives its deterministic surface atlas. It does not
construct a complete narrative model.

```scala
import storymodel4s.core.*

val source = StorySource
  .fromText(
    "One night two young men left Egulac.",
    title = Some("A short story")
  )
  .toOption
  .get

val atlas = SurfaceAnalyzer.analyze(source)

atlas.byKind(SurfaceUnitKind.Sentence).size // 1
```

## Inspect the acceptance fixture

The `fixtures` module exposes the hand-authored *War of the Ghosts* model and its plain-language
expectations. It is appropriate for learning the narrative types and testing downstream consumers.
It is not a template for bypassing acquisition in production.

```scala
import storymodel4s.fixtures.wog.*

val model = WarOfTheGhostsModel.model
val expectations = WarOfTheGhostsExpectations.all

expectations.map(_.phenomenon)
```

## Choose the next layer deliberately

- Need evidence spans, identifiers, claims, or provenance? Start in `core`.
- Need typed local meaning? Add `proposition`.
- Need entities, situations, contexts, and narrative relations? Add `story`.
- Need recall units and recall-side relations? Add `recall`.
- Need partial source alignment and signatures? Add `align`.
- Need embeddings? Read ADR 0001 before choosing a portable baseline or JVM adapter.
