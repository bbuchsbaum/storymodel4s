A word-level measure becomes useful only when it stays attached to the words it describes. This
example assigns synthetic imageability ratings to tokens, then computes four-word window means.

<pre><code class="language-scala">{program}</code></pre>

The replay gate records this exact output:

<pre><code>{output}</code></pre>

The first two windows have four observed lexical tokens, so both policies return the same mean. The
third window has two observations for three eligible words. `IgnoreMissing` reports the mean of the
two available values; `RequireMinCoverage(0.75)` reports `Missing(Excluded)`. The final window has no
observed value.

| Window | Coverage | Ignore missing | Require 75% |
| --- | ---: | ---: | --- |
| Red boats crossed quietly | 4/4 | 4.80 | 4.80 |
| crossed quietly Abstract ideas | 4/4 | 2.55 | 2.55 |
| Abstract ideas remained | 2/3 | 1.60 | Missing |
| remained | 0/1 | Missing | Missing |

The policy becomes part of the derived feature-space identity. A downstream analysis can therefore
tell which rule produced a value, and each window keeps its observed and eligible counts.
