## What exists now

storymodel4s is a Scala 3 source library for representing written stories, recalls of those
stories, and partial mappings between the two. Its central move is to keep surface evidence,
narrative structure, recall structure, and uncertainty separate enough that a reader can ask how
each conclusion was made.

<Evidence

  source="README.md and the current module graph"
  href={sourceLink('README.md')}
 />

The current repository includes typed narrative and recall models, alignment machinery, a
researcher-reviewed acceptance fixture, deterministic lexical embedding baselines, and JVM-only
structural and local ONNX adapters. Embeddings remain feature views: they can retrieve or compare;
they do not become narrative claims.

## What does not exist yet

There is no released library artifact, and APIs may change without notice. A raw story does not yet
flow unattended into a complete accepted model. The main story fixture is hand-authored, and a
local encoder's existence is not evidence that it improves recall alignment.

That boundary is not fine print. It determines the path through this guide: first understand one
thing the current representation demonstrably preserves, then learn the concepts, and only then
inspect the Scala surface.

## Begin with a difficult distinction

In *The War of the Ghosts*, a wound is reported in speech, the wounded state remains a hypothesis,
and a conflicting bodily state is explicitly negated in the narrated world. A flat event list can
silently promote the report to fact. The fixture is designed to make that mistake visible.
