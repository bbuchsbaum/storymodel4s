# Synthetic recall-clock fixture

All text and numbers here were authored for this test. No participant transcript,
annotation, gold label or video content was copied.

`words.csv` deliberately includes a quoted comma, a quoted newline, an empty word
and a missing Princeton onset. All three CSV data records must survive. Its
OpenNeuro word onsets are `7.5`, `8.750000000000001` and `11.75`; its Princeton
onsets are `0`, `1.25` and missing. The second paired difference is exactly
`7500000000000001/1000000000000000`, so converting through binary floating point
or silently imposing a universal 7.5-second correction changes the answer.

`lineage.json` binds the exact bytes and record/missing counts of both CSVs.
`aliases.json` assigns alias 05 to canonical source 06 and leaves source 05
(`omitted.csv`) without an alias. These are synthetic identities that reproduce
the kind of distinction required by the actual intake. Filename arithmetic must
not substitute for the digest-bound mapping.

`expected.json` contains hand-authored expected selected onsets and exact paired
differences. It was not generated by `recall_clock.py`. Tests additionally build
small malformed, changed-byte and extreme-number variants, updating the synthetic
manifest only when testing parsing after byte admission.
